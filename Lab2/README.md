# Lab 2 – Loops, Number Theory & Control Flow

This folder contains programs based on loops, conditional statements, number theory problems and control flow in Python.

## Programs

1. `prime.py` - Check prime numbers and print prime numbers in a range.
2. `armstrong.py` - Check Armstrong numbers and print them in a range.
3. `perfect_number.py` - Check perfect numbers and print them up to a limit.
4. `palindrome.py` - Check palindrome numbers and strings.
5. `fibonacci.py` - Generate Fibonacci series using loops and recursion.
6. `pattern_printing.py` - Print different star and number patterns.
7. `number_guessing_game.py` - Create a number guessing game.
8. `menu_driven.py` - Create a menu-driven program using different number operations.

## Analysis

The programs in this lab demonstrate the use of loops, conditional statements, functions, recursion and basic problem-solving techniques in Python.
