
# Lab 6 - Control Structures, Simulation & Search Algorithms

This lab contains Python programs based on control structures, simulations and search algorithms.

## Programs

1. `atm_simulation.py` - Simulates basic ATM operations such as PIN verification, balance checking, deposits and withdrawals.
2. `computer_guesses.py` - Uses the binary search algorithm to guess a number selected by the user.

## Concepts Used

- While loops
- Conditional statements
- User input
- Simulation
- Binary search
- Basic problem-solving
