# Lab 3 – Concentric Number & Star Patterns

This folder contains Python programs for printing concentric number patterns and different star patterns using loops.
## Programs

1. `number_pattern.py` - Prints a concentric number square pattern using nested loops.
2. `pattern_matching.py` - Prints different star patterns such as square, triangle, diamond and other designs.

## Concepts Used

- Nested loops
- For loop
- Print statements
- String multiplication
- Min function
- Pattern logic
