# Lab 1 – Python Fundamentals & Basic Syntax
This folder contains Python programs based on fundamental concepts and basic syntax.

## Programs

1. `variable_practice.py` - Practice variables and identifiers.
2. `greeting.py` - Display a greeting using user details.
3. `arithmetic.py` - Perform basic arithmetic operations.
4. `celsius_to_fahrenheit.py` - Convert Celsius into Fahrenheit.
5. `string_manipulation.py` - Perform basic string operations.
6. `escape_sequence.py` - Demonstrate escape sequences.
7. `calculator.py` - Create a simple calculator.
